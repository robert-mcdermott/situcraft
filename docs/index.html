Documentation

SituCraft opens the output of a 10x Genomics Xenium run, checks it, and shows the tissue, its transcripts and its cells at any zoom. From there it segments, types and reviews the cells, asks how the tissue is organized, and compares groups of subjects, keeping every decision on record. Everything runs on your computer; your data are never uploaded.

A path through it

Each page is a subject, in the order an analysis usually goes. Start with Getting started and an example; the worked examples there answer a question on each subject step by step.

How it works

  • One program, on your computer. SituCraft is a single file with nothing else to install. It reads every file of a bundle with its own readers, never changes, moves or copies a bundle, and sends nothing anywhere.
  • Checked before it is used. A bundle is checked before analysis, and the run's recorded metrics are recomputed from its data. Each method is validated against an independent implementation or a known truth, with the numbers on the Science page.
  • Everything is an artifact. Segmentations, comparisons, clusterings, labels, graphs and analyses are kept with their lineage, parameters, seeds and the SHA-256 of their files. The same inputs and settings give the same result on any computer.
  • Nothing is lost. Decisions and reviews are appended, never removed; filters, names, marker sets, regions and alignments are kept as versions. Undo covers every change.

References

Two references stay in the repository: Formats, every file SituCraft reads and writes, and the remote control reference, every action a script can send. The changelog says what each release added.
